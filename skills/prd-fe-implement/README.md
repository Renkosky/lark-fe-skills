# PRD FE Implement

[English](#english) | [中文](#中文)

## English

Implement frontend work from the detailed spec generated by `prd-fe-task`. Defaults to one Task per run for review; an explicit batch/all-tasks request continues sequentially.

```text
$prd-fe-implement Implement Task 1 from <implementation-spec.md>
$prd-fe-implement Continue the next task
```

Reuses existing components and APIs, mocks unavailable behavior, validates the implementation and records progress in the spec. A complete local spec needs no Lark access. Real backend integration remains a separate phase.

## 中文

根据 `prd-fe-task` 生成的开发细则实现前端需求。默认一次一个 Task，方便 review；明确要求批量或全部完成时，按顺序持续开发。

```text
$prd-fe-implement 实现 <implementation-spec.md> 的 Task 1
$prd-fe-implement 继续下一个任务
```

复用已有组件和接口，对未就绪行为使用 Mock，完成验证后在细则中记录进度。完整本地细则不依赖 Lark 授权，真实接口联调留在后续阶段。
